# 五条悟：管理员身份技能初版

## 获取与退出

```text
asylum_gojo <CID> 1
asylum_gojo <CID> 0
asylum_gojo_status <CID>
asylum_gojo_energy <CID> <0–200>
```

都直接在 RCON/服务端控制台使用，自动定位目标房间。只能由管理员显式变身；五个技能不在普通池、大神池、升级模块或 `asylum_give` 的装备目录里，也没有任何模式自动触发入口。

开关不会补满血甲。身份在同一房间死亡/重生和重开比赛后保留，技能冷却不靠 K 重置；离开房间、换图或断开后清除。开关本身不重置已有技能冷却。关闭后重新分配普通装备。GG、感染者、JGN 巨人和无武器大厅不能开启。

实际变身时全服聊天提示：`那双眼睛，毋庸置疑——玩家名 变成了五条悟。` 重复开启不重复播报，关闭身份不播报这句。

默认是巡回大厅，先在 RCON 切战斗图，例如：

```text
room_setting 0 asylum_map asylum_rooftops
asylum_gojo 0 1
```

## 五个槽位

按 `1/2/3/4/5` 切换，左键使用；切换武器、受冻结或领域定身会取消未发出的蓄力。蓄力时移动速度约降低 20%，不锁死移动或跳跃。最低蓄力：苍/赫 0.5 秒、茈 1 秒、领域 0.8 秒；没达到时松开直接取消，不消耗咒力或冷却，点一下不再能发射。脑损伤下咏唱更慢，无 CD 不跳过最低蓄力。

| 槽位 | 技能 | 初版机制 |
|---|---|---|
| 1 | 苍拳 | 前方约 4.75 格攻击范围，苍把目标拉向拳头；普通拳基础 34 点加苍的 6 点增伤，共 40。冷却 0.65 秒。 |
| 2 | 苍 | 短按蓄力松开就是普通小苍；持续蓄力至 1.8 秒才是最大输出。半径从 36 到 224，最大体积相比上一版翻倍；吸力范围为半径三倍。速度 17–20 单位/tick，最大苍约为原速度四倍。强化吸力把目标牵向移动重心，受吸目标速度上限提高到 44，并避免被持有武器的减速限幅吃掉。再次按住左键引向鼠标，松开后保留惯性；大苍只比小苍略有惯性。存在最多 8 秒，中心碰墙消失。 |
| 3 | 赫 | 1.3 秒满蓄力，半径 18–40，速度 30–38 单位/tick。按赫实际飞行朝向的前方锥形判直击，向上/向下打头顶同样有效；不固定按世界横轴判断。直击不再给一次弹飞冲量，而是抓住目标，持续按赫前方位置推着走，每约 40ms 扣 2 血。擦边仅弹飞一次、不掉血，之后真正正面碰上仍可抓住。角色始终走地图碰撞，不穿墙；墙或领域挡住目标且距离过远时结束携带。存在最多 3 秒，中心碰墙消失。 |
| 4 | 茈 | 2.6 秒满蓄力，半径 50–150，速度 70–100 单位/tick。蓄力显示咒词，松开后高速穿墙发射。一次对同一目标仍最多造成 40–70 伤害，不秒满血普通玩家。每穿过 1 格实墙，半径只缩小 0.16，最低 24；穿墙不增加伤害。苍赫相撞也会生成茈，归赫的释放者。存在最多 3 秒。 |
| 5 | 无量空处 | 按住 0.8 秒展开，固定在释放时的位置，球形直径 40 格，持续 6 秒。边界挡住领域外的人进入，最初在里面的人可离开、但离开后不能重新进入；释放者不受边界限制。释放者及距其 3 格以内的人不受定身。其余有效敌人看到纯黑背景 quad，并定身，每 0.5 秒扣 1 血。脱离后有 15 秒脑损伤：移速/加速度降至 65%，五条悟咏唱更慢、施术冷却加倍。冷却 45 秒。 |

苍中同时有至少两个有效目标时，才产生互相挤压伤害：每约 0.25 秒分别扣 2–4 血。一个目标被吸住不会凭空持续扣挤压伤害。

苍、赫、茈的基础冷却分别为 5、5、12 秒；每名释放者同类球体最多同时一个，避免无 CD 时叠成无限实体。领域不叠加自身重复施放。伤害和控制遵守房间/队友限制；Boss 仍保留自身的免击退/控制规则。

主动发射茈和苍赫合成共用同一茈冷却。成功合成后，赫的释放者也进入 12 秒茈冷却（脑损伤时 24 秒）；冷却中不能再次合成，苍与赫继续各自运动，不会为失败的合成额外扣咒力。开启无 CD 测试时才跳过这项冷却。

## 咒力蓝条

上限 200，与 100 点“无限”屏障值分开。头顶有本人可见的蓝色条，HUD 显示咒力格条和数值，原弹药图标也表示剩余咒力。

| 技能 | 单次消耗 |
|---|---|
| 苍拳 | 3 |
| 苍 | 12–32，随蓄力提高 |
| 赫 | 14–26，随蓄力提高 |
| 茈 | 28–50，随蓄力提高 |
| 无量空处 | 70 |

停止消耗 2 秒后，每秒恢复 6 点。咒力不足时不释放、不进入冷却；开关身份、K 和重开不刷满蓝条。`asylum_gojo_energy <CID> <0–200>` 可由 RCON 手动调整，便于你测；无 CD 不等于无限咒力。

## 被动

- **无限**：有限屏障，不是常驻无敌。至少 2 秒没施术时能抵挡敌方伤害，消耗 15–40 点屏障值；上限 100。连续火力会击穿，施术时不能靠它无条件挡伤。停止施术 3 秒后每秒恢复 5 点；环境伤害和无量空处不被它抵挡。测试锁血模式下不启用拦截，方便测命中与控制。
- **无限踏空**：普通空中跳跃次数用完后，再次按下跳跃可消耗 12 点无限继续跳。每按一次只付一次，按住不连跳，正常的一/二段跳不收费；冻结、领域定身、赫携带和地图禁跳时不生效。
- **反转术式**：停止使用技能 4 秒后，每秒缓慢恢复 2 HP；仍有在飞的术式或领域时不视为停用技能。不会与普通 Asylum 脱战回血叠加，也不会额外恢复护甲。
- **六眼**：服务端实体可见/发送范围为正常的 1.75 倍，不强行改变客户端镜头或缩放设置。

## 地图与画面

已给现有地图加入 `gojo_domain_black` 背景 quad 包络，图像使用用户提供的 `assets/gojo/unlimited-void.jpg` 原图，不裁剪、不改色，保持原始比例，超出画面的部分由黑底补齐。它放在原背景之后、游戏层和角色之前，不遮掉角色。只有受领域影响的客户端才获得对应地图时钟，其他人不变；结束后快速淡出。

图片 quad 使用当前 DDNet 0.6 地图时钟路径。临时时钟也会影响受影响者的 HUD 时间显示，不改变服务端实际比赛计时。需要开启地图装饰，并同时更新服务端与地图。自己的地图可运行：

```text
python scripts/asylum_map_assets.py data/maps/自己的地图.map
```

苍/赫/茈用原生激光形状和 [DDNet 激光颜色类型](https://github.com/ddnet/ddnet/blob/master/src/game/client/components/items.cpp) 区分，颜色可受客户端配色设置影响，较旧客户端保留普通激光形状。当前没有另加五条悟录音，咒词为文字。

特效按技能区分：苍拳有指节、苍月弧和出拳残影；苍为多臂空间旋涡及吸入碎片；赫为炸裂星芒和多层排斥冲击弧；茈恢复圆球，保持圆形轮廓、内层能量轨道及表面裂纹，不再是尖头能量梭/穿甲弹；咏唱阶段有苍赫两极汇聚；领域边界加入刻印符文和内部信息噪点，挡人时有碰撞闪光。踏空时脚下出现短暂空间踏板。

## 手动测试用指令

```text
asylum_test_nocd <CID> 1
asylum_test_reset_cd <CID>
asylum_test_god <CID> 1
asylum_test_inf_cursedenergy <CID> 1
asylum_test_inf_cursedenergy <CID> 0
```

无 CD 不跳过蓄力、咏唱、领域持续时间，也不允许同类实体无限叠加。关闭五条悟身份后才能用普通配装指令替换装备。

`asylum_test_inf_cursedenergy` 同时开关无限咒力和无限“无限”屏障值，直接在 RCON 使用，不加 `room_setting`。开启时补满并保持咒力 200、无限 100，施术、屏障挡伤和额外踏空不消耗它们；不跳过冷却、最低蓄力、领域/冻结等状态限制，也不让无限在施术时无条件挡伤。可以先给玩家开测试标记，再变身五条悟；死亡、重生和换房后保留，断开重连恢复关闭。关闭后后续使用恢复正常消耗。

按用户要求，本轮只编译，不启动服务器，不执行联机/玩法测试。
