# 大神武器地图素材

## 当前资源

- `jumpscare-rock.png`：用户提供的巨石强森原图。图片本身未裁剪；地图 quad 将方图拉伸成 **4:3**（1600 × 1200 地图单位），顶点透明度为 **160/255 ≈ 63%**。
- `reserved/dancing-cat-original.png`、`reserved/dancing-cat-transparent.png`：此前猫图的原件和透明版，留给后续武器，当前不嵌入地图。透明版由内置图片工具按“只移除白色背景，保留姿势、灰度纹理和轮廓”处理。
- `sounds/bf_*.opus`：用户提供的 FNF Boyfriend WAV 转换得到的 22 段单声道 48 kHz Opus，播放时不叠加喇叭、刮碟等额外音效。
- `source/vine-boom.mp3`：用户提供的 `D:\download\QQ\vine-boom.mp3` 原件。
- `sounds/vine_boom.opus`：该 MP3 转换得到的地图音效，用于巨石强森跳脸，也用于原有摩艾等 Vine Boom 场景。跳脸不再使用尖叫、心跳或故障音效。
- `source/the-world.mp3`：用户提供的 `za-warudo-toki-wo-tomare_WJVdsYt (1).mp3` 原件。
- `sounds/the_world_00.opus` 至 `the_world_11.opus`：同一完整原录音的 12 档音量版，只有增益不同，没有合成新声音、裁剪音节或改变语速。

此前的 19 段合成音效已从素材目录和当前地图的声音表、原始音频块中移除；转换脚本也不再生成任何合成音效。其他武器只用单个游戏自带提示音，不再叠加定时音效序列。附件视频没有使用。所有外部图片、录音均为用户提供，未另行声明其资源许可。

## 装备与测试

本分支共 58 项：36 件普通随机装备、5 个升级模块、5 件升级武器、12 件大神装备。大神随机概率默认 0%，only 默认关闭；保留 main 的 ID 0–45，大神装备使用 46–57，旧大神 ID 32–43 已顺延。

### 动感星期五（ID 55，远程）

0.2 秒一次，向准星发射箭头，箭头图形按左、下、上、右循环。单箭头 18 伤、4 击退、最长飞行 1 秒；碰墙、命中或发射者死亡/换房时消失。每次实际开火随机播放一段对应方向的 BF 音节。麦克风用激光线条描边，普通客户端仍保留基础武器贴图。

### 恋符MasterSpark（ID 56，远程）

参考 [THBWiki 的 Master Spark](https://thwiki.cc/Master_Spark) 中蓄力后发射极粗激光的描述，做二维适配，而非完整复刻原作。

- 蓄力 0.6 秒，炮口显示旋转魔法阵，然后持续发射 2 秒。
- 射程 1400 地图单位，光束宽度由炮口的 64 逐渐扩大到末端的 208；使用 33 条激光描绘，不是单条细激光。
- 每 0.12 秒造成 12 点伤害，可以贯穿多名敌人，但墙体会阻挡每条光束及其伤害。
- 蓄力时可自由瞄准，发射后最多每秒转向约 80 度；持有期间限制水平移动速度。
- 12 秒冷却；切武器、死亡、冻结、离开房间或回合结束会中断，不获得无敌。
- 只使用游戏原有激光音效，不新增合成音效。

### The World（ザ・ワールド）（ID 57，特殊）

- 触发立即播放完整原声；前 **1 秒**正常运行。从音频第 1 秒开始，除使用者外的所有实体用平滑曲线逐渐降低 Tick 推进频率。
- 原录音约 **4.412 秒**，编码后容器时长约 **4.418 秒**。在 50Hz 服务端第 **4.42 秒**才完全暂停，保证录音完整播放；完全停止持续 **5 秒**。
- 复用现有 `TickPaused()` 和客户端 `GAMESTATEFLAG_PAUSED`。使用者本人继续正常 Tick；所有投射物，包括使用者现有和新射出的子弹/激光、箭头、召唤实体、其他人的技能与物理推进，都会渐慢、暂停，结束后继续。激光第一次命中也会延后到恢复，不能靠构造函数绕过暂停。
- 时停覆盖**当前房间全地图**，不按距离限制，也不影响其他房间。使用者死亡、离房、观战、进入个人暂停，或回合重置时取消；不通过 DDNet 的冻结地砖/`Freeze()` 来模拟。
- **60 秒冷却**，整段语音前摇、渐慢和时停期间都不减少；恢复后开始计时。因此无击杀时，从触发到下次就绪约 **69.42 秒**。冷却属于玩家会话，不会被死亡、换武器、重抽、换房或换回合重置（断开重连是新会话）。
- 每次有效敌方击杀最多减 **2 秒**，每次释放累计最多减 **10 秒**；自杀、队友和热身击杀不返还。时停期间获得的返还排队，恢复后一次结算，停止时不会直接减少冷却。
- 声音按**触发瞬间**听者和使用者的距离选择一档：最近原音量，地图最远处约 15% 音量。通过每人单独发送地图音效，不受普通空间音效的短距离截断影响；不是随玩家移动实时更新音量。客户端关闭声音仍然听不到。
- 灰色屏幕 quad 从音频第 1 秒开始，随渐慢阶段淡入到约 **47%** 覆盖透明度；停止期间维持，恢复后约 **0.256 秒**快速淡出。完全停止期间同步地图包络的时钟也停止。

灰色覆盖与跳脸一样使用 **DDNet 0.6 连接路径**；0.7 连接仍有时停和原声，但没有这两种时间线 quad。灰色不是客户端后处理的真正去色，而是灰色半透明覆盖。同步地图装饰在变慢阶段会受临时地图时钟影响，HUD 回合时间也会临时偏移；实际比赛计时不使用这份展示时钟。

在 Asylum 房间内通过 RCON 指定装备：

```text
asylum_test_loadout <CID> 46 56 53
# 同时测试恋符MasterSpark和The World
asylum_test_loadout <CID> 46 56 57
```

## 地图资源与跳脸

音效和图片都内嵌于 `data/maps/*.map`、`data/maps7/*.map`。客户端随地图下载，不需要另装资源包。**测试必须同时更新服务端和地图**。

跳脸是受惊吓者独享的半透明前景 quad：触发后立即出现，随后在 **1.28 秒内线性淡出到透明**，不再停留后突然消失。同步颜色包络 `asylum_jumpscare` 的四个时间点为 `0ms`（隐藏）、`2147481087ms`（出现并开始线性淡出）、`2147482367ms`（完全透明）、`2147483647ms`（维持透明，32 位上限）。触发时只给该玩家发送临时偏移的地图时钟，结束后恢复；不修改实际回合计分和比赛时间。不过客户端 HUD 时钟及其他同步地图动画在这 1.28 秒内也受临时偏移影响。

图片跳脸使用 DDNet **0.6 连接路径**；0.7 保留广播和攻击效果，不发送负数的 0.7 游戏起始 tick。需开启地图装饰，`cl_overlay_entities 100` 会隐藏 quad。地图音效网络事件需要较新的 DDNet 客户端。未嵌入资源的自定义地图使用单个内置音效作为回退，不触发图片时间偏移。

## 管理员测试指令（`asylum_test_`）

The World 的冷却保存在玩家会话上，而不是单件武器对象上。因此 K 自杀、重新执行 `asylum_loadout`、重抽、换房、换回合都不会清掉冷却。这是正式玩法的防重置机制。

以下指令**直接在 RCON/服务器控制台使用，不用 `room_setting` 前缀**。按目标玩家的当前房间自动执行，不注册为普通玩家聊天指令。下面只需将客户端 `0` 换成实际玩家 ID：

```text
# 给 CID 0 开启持续无冷却（默认关闭，不影响别人）
asylum_test_nocd 0 1
# 关闭无冷却，后续使用恢复正常冷却
asylum_test_nocd 0 0
# 仅把 CID 0 当前冷却清空一次
asylum_test_reset_cd 0
# 给 CID 0 开启/关闭测试无敌
asylum_test_god 0 1
asylum_test_god 0 0
# 快速换一件：自动确定槽位，其他两件不变；同时切到新装备
asylum_test_weapon 0 56
asylum_test_weapon 0 57
# 三槽配装与查看装备 ID
asylum_test_loadout 0 46 56 57
asylum_test_items
```

无冷却标记在死亡、重新发装备和换房后仍保留，断开重连恢复默认关闭。开启时立即清空当前 Asylum 武器、E/R、重抽的冷却以及 The World 会话冷却；新拿到的装备同样无冷却。单次重置不改变是否开启无冷却、不更换装备、不恢复血甲，也不取消正在进行的技能。

无敌是**锁血靶子模式，不是攻击免疫或取消命中判定**。标记属于该玩家会话，默认关闭，死亡重生后仍保留；受到有效命中时血量、护甲不减少，但命中音效、伤害指示、受击表情、击退、吸引、普通/深度冻结、审判换位、巨石强森跳脸和 The World 时停都照常。开启时取消当前出生/临时保护，后续出生也不额外给予出生盾，便于立即测试命中；不自动补血甲，不解除已有冻结。仍遵守队友免伤、真正护盾和模式限制，不给攻击者刷击杀、实际伤害充能或吸血收益。死亡地块不杀死锁血玩家，K自杀、切队/房间清理仍可正常删除角色；不会恢复淘汰角色的参赛资格。

快速换武器只更新该装备类别对应的槽位，会清除当前临时武器覆盖并切换到指定装备，其他普通槽位的冷却/充能以及血甲不变。The World 的会话冷却仍不会因为换武器而清空；要马上测试用单次重置或无冷却开关。固定配装的 GG、感染者和 JGN 巨人仍保留原模式限制，任意装备测试请用 FFA。原 `room_setting <房间ID> asylum_test_...` 和 `asylum_loadout` 保留兼容；新增测试指令均用 `asylum_test_` 前缀，不保留尚未发布的 `asylum_nocd`/`asylum_reset_cd` 名字。

`asylum_test_items` 可以不填参数：RCON 使用本人所在房间，本地控制台或 econ 使用第一个就绪的 Asylum 房间；也可以写 `asylum_test_items <CID>` 来指定查看该玩家房间的装备表。其他五个指令都用第一项 CID 定位房间，目标未连接、房间未初始化或不是 Asylum 模式时只给出提示，不改其他房间或玩家。

无冷却**不跳过前摇、蓄力、持续时间、R 的伤害充能要求或游戏暂停**。一个房间只能有一场进行中的 The World，必须结束后才能再次触发；MasterSpark 也不会给同一使用者叠加多条正在引导的光束。关闭测试开关后，下一次正常使用重新开始正常冷却。

## 重新转换与打包

当前地图内有 **35** 个技能录音样本（22 个 BF、1 个 Vine Boom、12 个 The World 音量版本），巡回大厅/Boss 地图另保留其背景音乐。需要 Python 3 和 ffmpeg 重新转换；普通构建与 CI 使用已打包的地图，不需要 ffmpeg：

```powershell
python scripts/asylum_sound_assets.py
# 仅重新转换 BF 时额外指定 --bf-wav "D:\新建文件夹\Fnf_BoyfriendWAV"
python scripts/asylum_map_assets.py
python scripts/test_asylum_map_assets.py
# 独立 C++11 时间线/冷却/声音距离规则测试（GCC 环境）
g++ -std=c++11 -Wall -Wextra -Werror -Isrc scripts/test_asylum_time.cpp -o build/test_asylum_time
./build/test_asylum_time
```

地图脚本保留既有地图数据索引、碰撞层、出生点、配置和图片，原位更新资源；迁移时清空已移除合成音效的数据块并调整声音索引。重复执行不会叠加新的声音或跳脸层。没有自动播放声音源，入服不会自动播放整套音效。

采用 DDNet 官方 UUID：[`map-sound-world@netevent.ddnet.org` / `map-sound-global@netmsg.ddnet.org`](https://github.com/ddnet/ddnet/blob/master/datasrc/network.py)，播放由客户端的 [MapSounds](https://github.com/ddnet/ddnet/blob/master/src/game/client/components/mapsounds.cpp) 处理。
